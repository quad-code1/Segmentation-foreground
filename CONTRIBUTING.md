# Contributing

Thanks for considering a contribution to this project.

## Ways to contribute

- **Bug reports**: open an issue with steps to reproduce, your OS/Python/OpenCV version, and sample input if possible.
- **Feature requests**: open an issue describing the use case before submitting a large PR, so approach can be discussed first.
- **Code contributions**: fork the repo, create a branch (`feature/your-feature` or `fix/your-fix`), and open a PR against `main`.

## Development setup

```bash
git clone https://github.com/<your-username>/foreground-segmentation.git
cd foreground-segmentation
pip install -r requirements.txt
```

## Guidelines

- Keep functions small and documented (docstrings for any public method).
- Match existing code style (PEP 8).
- Add/update usage examples in `examples/` if you change the public API.
- Test on at least one video file and webcam input before submitting, where relevant.

## Code of conduct

Be respectful and constructive. Assume good intent in reviews and issues.
